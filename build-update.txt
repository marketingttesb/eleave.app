# Tauri Update Release Guide (GitHub Auto Updater)

## 1. Update version

### package.json

Cari:

```json
"version": "0.1.1"
```

Tukar:

```json
"version": "0.1.2"
```

---

### src-tauri/tauri.conf.json

Cari:

```json
"version": "0.1.1"
```

Tukar:

```json
"version": "0.1.2"
```

Pastikan dua-dua sama.

---

# 2. Build app

Run:

```bash
npm run tauri build
```

Tunggu sampai siap.

---

# 3. Cari file output

Biasanya dekat:

```bash
src-tauri/target/release/bundle/nsis/
```

Akan ada:

```text
Tien Tien E-Leave_0.1.2_x64-setup.exe
Tien Tien E-Leave_0.1.2_x64-setup.exe.sig
```

---

# 4. Generate latest.json

Buat file `latest.json`

Paste:

```json
{
  "version": "0.1.2",
  "notes": "Update Manage Personal Leave",
  "pub_date": "2026-05-29T08:00:00Z",
  "platforms": {
    "windows-x86_64": {
      "signature": "PASTE CONTENT FROM .sig FILE HERE",
      "url": "https://github.com/marketingttesb/eleave.app/releases/download/v0.1.2/Tien%20Tien%20E-Leave_0.1.2_x64-setup.exe"
    }
  }
}
```

---

# 5. Copy signature

Buka file:

```bash
Tien Tien E-Leave_0.1.2_x64-setup.exe.sig
```

Copy semua content.

Paste ke:

```json
"signature": ""
```
