# Tauri Update Release Guide (GitHub Auto Updater)

## 1. Update version

### package.json

Find:

```json
"version": "0.1.1"
```

Change to:

```json
"version": "0.1.2"
```

---

### src-tauri/tauri.conf.json

Find:

```json
"version": "0.1.1"
```

Change to:

```json
"version": "0.1.2"
```

Make sure both versions match.

---

# 2. Build app

Run:

```bash
npm run tauri build
```

Wait until the build completes.

---

# 3. Locate output files

Typically found at:

```bash
src-tauri/target/release/bundle/nsis/
```

You will see:

```text
Tien Tien E-Leave_0.1.2_x64-setup.exe
Tien Tien E-Leave_0.1.2_x64-setup.exe.sig
```

---

# 4. Generate latest.json

Create a file called `latest.json`

Paste:

```json
{
  "version": "0.1.2",
  "notes": "Update Manage Personal Leave",
  "pub_date": "2026-05-29T08:00:00Z",
  "platforms": {
    "windows-x86_64": {
      "signature": "PASTE CONTENT FROM .sig FILE HERE",
      "url": "https://github.com/marketingttesb/eleave.app/releases/download/v0.1.2/Tien%20Tien%20E-Leave_0.1.2_x64-setup.exe"
    }
  }
}
```

---

# 5. Copy signature

Open the file:

```bash
Tien Tien E-Leave_0.1.2_x64-setup.exe.sig
```

Copy the entire content.

Paste into:

```json
"signature": ""
```

---

# 6. Commit code

```bash
git add .
git commit -m "release v0.1.2"
git push
```

---

https://github.com/marketingttesb/eleave.app/releases

Click:

```text
Draft a new release
```

```text
v0.1.2
```

Upload 3 files:

